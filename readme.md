# Big Desktop Clock Wallpaper

Use `preview.html` as a live desktop wallpaper on Windows with Lively Wallpaper.

## Set it up

1. Install and open [Lively Wallpaper](https://www.microsoft.com/store/apps/9NTM2QC6QWS7) from the Microsoft Store, or get it from [livelywallpaper.net](https://www.livelywallpaper.net/).
2. In Lively, choose **Add Wallpaper** (the **+** button) and browse to this folder.
3. Select `preview.html` and confirm adding it if Lively asks.
4. Select the new clock wallpaper in Lively's library to apply it to your desktop.

Keep `preview.html` in its current folder after adding it. The clock uses your Windows local time and date, and updates automatically while the wallpaper is running.

If the page opens in a browser instead, return to Lively and add `preview.html` through **Add Wallpaper**; opening the file normally does not set it as your desktop wallpaper.
